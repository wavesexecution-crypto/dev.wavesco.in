# dev.wavesco.in

A premium studio portfolio for WavesCo — design, redesign, and deploy modern websites.

## Stack

- Next.js 15 (App Router)
- TypeScript (strict)
- Tailwind CSS v4
- Framer Motion
- Geist + Instrument Serif + Geist Mono via `next/font`

## Develop

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Build

```bash
pnpm build
pnpm start
```

## Notes

- All project cards are placeholders, marked as such.
- Honors `prefers-reduced-motion`.
- Single-page composition in `app/page.tsx`.
- Design tokens defined as CSS variables in `app/globals.css`.
